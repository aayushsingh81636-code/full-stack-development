• READONLY ATTRIBUTE

    when we use the readonly attribute ,the user can see the value but cannot modify it.

  • DISABLED ATTRIBUTE

    when we use the disabled attribute ,the user can see the value but cannot modify it and it is not submitted with the form.

  • SIZE AND MAXLENGTH ATTRIBUTES

    The size attribute specifies the visible width of the input field, while the maxlength attribute specifies the maximum number of characters allowed in the input field.

  • MAX AND MIN ATTRIBUTES

    The min and max attributes are used with input types like number, range, date, etc., to specify the minimum and maximum values allowed.

  • MULTIPLE ATTRIBUTE

    The multiple attribute allows users to select multiple values from a list of options.

  • PATTERN ATTRIBUTE and PLACEHOLDER

    The pattern attribute specifies a regular expression that the input value must match to be considered valid. Placeholder text provides a hint to the user about what to enter.Required attributes ensure the input is not left empty.

  • AUTOFOCUS ATTRIBUTE

    The autofocus attribute automatically focuses the input field when the page loads.

  • AUTOCOMPLETE ATTRIBUTE

    The autocomplete attribute specifies whether the input field should have autocomplete enabled.
